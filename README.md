# acms-block-editor-image-float

ブロックエディターの画像ブロックにテキスト回り込み（フロート）配置を追加する a-blog cms プラグイン。

> **開発中**です。現在はひな型（[appleple/acms-plugin-skeleton](https://github.com/appleple/acms-plugin-skeleton) v1.0.3）から作った初期状態です。

## ドキュメント

- [設計書](docs/design.md)

## 動作環境

- a-blog cms 3.2 系（ブロックエディターのプラグイン拡張基盤 `ACMS.plugins` が必要）
- PHP 8.1 – 8.5
